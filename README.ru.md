**SwagEda** — это высокопроизводительный агрегатор рецептов и кулинарный портал, созданный с упором на скорость, доступность и современные подходы во фронтенд-разработке. Проект служит демонстрацией создания масштабируемых и SEO-оптимизированных контентных платформ с использованием **Astro** и **Tailwind CSS v4**.

В этом проекте уделено огромное внимание UX/UI, стандартам семантического веба, передовым методам оптимизации производительности и чистоте кода.

---

## ✨ Возможности и реализованный функционал

- **🧩 Чистый код и компонентная архитектура:** Проект тщательно разбит на гранулярные, высокосвязные UI-компоненты (`Button`, `Card`, `RatingStars` и т.д.). Строгое разделение ответственности гарантирует, что кодовая база остаётся масштабируемой, легко поддерживаемой и удобной для рефакторинга в будущем.
- **🚀 Экстремальная производительность:** Мгновенная загрузка страниц благодаря гибридному рендерингу Astro. Использование Edge-кэширования (`stale-while-revalidate`) позволяет отдавать страницы моментально, сохраняя при этом актуальность динамических данных.
- **🔍 Продвинутый поиск:** Фильтрация в реальном времени по категории, сложности и ключевым словам в огромной базе из более чем 31 000 рецептов.
- **🌗 Умная система тем:** Сохраняемая тёмная и светлая тема, работающая через CSS-переменные Tailwind v4. Учитывает системные настройки пользователя без эффекта мигания (FOUC).
- **⚡ Интерактивная система рейтингов и лайков:** Встроенная система оценок (5 звёзд) и лайков с синхронизацией через backend API. Локальное кэширование в `localStorage` обеспечивает мгновенный визуальный отклик, красивые всплывающие уведомления (Toast) информируют об успехе или ошибке, а сетевые сбои обрабатываются безопасно для пользователя.
- **📝 Умный чек-лист ингредиентов:** Интерактивный список ингредиентов, позволяющий пользователям отмечать уже добавленные продукты в процессе готовки.
- **📹 Поддержка мультимедиа:** Встроенный плеер YouTube с удобным переключением вкладок "Текст/Видео" для улучшения пользовательского опыта.
- **🖨️ Оптимизация для печати:** Специально написанные CSS media-запросы для красивой печати рецептов (скрывают лишний UI, оптимизируют раскладку для бумаги).
- **🛡️ Безопасный API Proxy:** Кастомный Astro Middleware выступает в роли прокси для запросов к Laravel-бэкенду, защищая секретные ключи, токены и решая проблемы CORS/CSRF.

## 🚀 Производительность и оптимизация

<p align="center">
  <img src="./img/lighthousepng.png" alt="Lighthouse 100 Performance Score" width="600" />
</p>

- **Zero-JS:** Основной контент отдаётся в виде чистого HTML. JavaScript загружается и гидратируется только для интерактивных "островов" (звёзды рейтинга, переключатель тем), что радикально снижает нагрузку на основной поток (main thread).
- **Продвинутое кэширование:** Использование HTTP-заголовков `Cache-Control` и CDN Edge Caching для минимизации TTFB (Time to First Byte).
- **Оптимизация изображений:** Повсеместное использование `astro:assets` для отдачи изображений в современных форматах (WebP/AVIF) с автоматической ленивой загрузкой (lazy loading).

---

## ♿ Доступность (A11y) и семантика

- **Семантический HTML5:** Строгое следование HTML5-разметке (`<main>`, `<nav>`, `<article>`, `<aside>`) для правильной структуры контента, понятной скринридерам.
- **Стандарты ARIA:** Корректное использование атрибутов `aria-live`, `aria-expanded`, `aria-pressed` и `role` во всех динамических компонентах.
- **Навигация с клавиатуры:** Высококонтрастные кольца фокуса (`focus-visible:ring-brand`), настроенные глобально, позволяют опытным пользователям и людям с нарушениями зрения полноценно управлять сайтом только с клавиатуры.
- **Цветовой контраст:** Тщательно подобранная палитра для светлой и тёмной тем, соответствующая стандартам AA/AAA, гарантирует отличную читаемость текста.

---

## 🔍 SEO

- **Схема JSON-LD:** Для каждой страницы рецепта автоматически генерируется микроразметка `Recipe` и `BreadcrumbList` для создания расширенных сниппетов (Rich Snippets) в Google.
- **OpenGraph и Twitter Cards:** Динамическая генерация мета-тегов для красивого и информативного шаринга ссылок в социальных сетях.
- **Канонические URL:** Строгое управление тегом `canonical` для предотвращения проблем с дублированием контента в поисковой выдаче.

## ⚙️ Установка и запуск

### Требования

- Node.js `>=22.12.0` (как указано в `package.json`)
- npm, pnpm или yarn

### Инструкция

1. **Клонируйте репозиторий:**

   ```bash
   git clone https://github.com/KbrYbk/recipe-frontend.git
   cd recipe-frontend
   ```

2. **Установите зависимости:**

   ```bash
   npm install
   ```

3. **Настройте переменные окружения:**
   Создайте файл `.env` на основе предоставленного `.env.example`:

   ```bash
   cp .env.example .env
   ```

   _Убедитесь, что вы заполнили пути к API и ключи проекта._

4. **Запустите сервер для разработки:**

   ```bash
   npm run dev
   ```

   Сайт будет доступен по адресу `http://localhost:4321`.

5. **Сборка для продакшена:**
   ```bash
   npm run build
   ```
   Готовый Node.js сервер для продакшена будет сгенерирован в папке `dist/`.

```text
├── components/     # Переиспользуемые UI-компоненты (Кнопки, Карточки, Звёзды)

```
